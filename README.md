# AI Pulse

Невеликий каталог AI-сайтів з пошуком. Дані беремо з публічного API freeserp.ai, показуємо картками, а сподобані сайти можна зберегти в обране.

## Що зроблено

- Темна тема в стилі Vercel/Linear: темний фон, неонові акценти, розмиття (backdrop-blur) у шапці.
- Адаптивна сітка: від 1 колонки на телефоні до 8 на великих екранах і телевізорах.
- Шапка з логотипом, пошуком і кнопкою "Favorites" (там же лічильник збережених).
- Картки сайтів: назва, посилання, короткий опис і зірочка для збереження в обране.
- Запит до API з `index=sites` і пошуком по "ai", усе через `async/await`.
- Skeleton-завантаження з shimmer-ефектом, поки йдуть дані.
- Стани "нічого не знайдено" і "помилка" (з кнопкою спробувати ще раз).
- Пошук по завантажених результатах, миттєвий. Якщо збігів мало, сам підвантажує наступні порції.
- Обране зберігається в `localStorage`, тож лишається після перезавантаження. Кнопка в шапці показує тільки збережені.
- Кнопка "Load more" підвантажує ще по 24 сайти (розмір порції в `CONFIG.PAGE_SIZE`).

## Як запустити

Потрібен Node 18 або новіший.

1. Покласти `index.html`, `app.js` і `server.js` в одну папку.
2. У цій папці виконати `node server.js`.
3. Відкрити http://localhost:3000.

Чому саме так, а не просто відкрити файл: сервер freeserp.ai віддає некоректний CORS-заголовок, і браузер блокує запит напряму. `server.js` сам ходить до API і віддає дані сторінці, тому проблеми немає. Live Server теж відкриє сторінку, але маршруту `/proxy` там нема, тож код піде через публічні проксі, а вони нестабільні.

## Що не встигли / що не ідеально

- Публічні CORS-проксі в списку запасні, покладатися на них не варто.
- Пошук працює по завантаженому, а якщо збігів мало (менше 12), сам підтягує ще до 5 порцій. По всій базі API (мільйони сайтів) він не шукає.
- Немає debounce на пошуку (на 24-100 карток це не проблема, на тисячі було б).
- Обране лежить тільки в одному браузері, без акаунтів і синхронізації.
- Ніяких тестів.
- Якість видачі залежить від API: інколи в результатах трапляються сайти, які до AI мало стосуються.

## Що доробили б далі

- Створення аккаунту, для збереження в БД favorites.
- Нескінченний скрол замість кнопки.
- Пошук по всій базі через API, а не тільки по завантаженому. Треба дізнатись, як API розуміє параметр `q`.
- Фільтри й сортування (за DR, датою запуску, категорією).
- Світла тема.
- Кеш відповідей, щоб повторні візити відкривались миттєво.
